# bwu
Better Windows (Utility)
Run this utility as admin or else some tweaks won't be applied properly.
Open Source Project to optimize windows and install other software to make the experience better, hence the title Better Windows (Utility)


This Project uses tweaks from XNETTWEAKS FREE UTILITY version: 4.5 from the official source, feel free to ask me questions on discord, telegram or send me an email.
